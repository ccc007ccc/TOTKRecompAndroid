# 2026-10-31：低帧优化与 Oryon Release 收尾

按用户要求完成本轮验证后，整理当前累积改动并交付普通 Release。当前性能基准是原空岛 slot_00、1×/60、
全幅前进和右转、穿插 Y/X、就绪后 60 秒自动退出；正常 2×/60 和长时间游玩仍是后续目标。
历史实验、负结果及实际范围保留在 [低帧记录](PHONE-LOW-FRAMES-20261031.md)，操作规范统一在 [Agent.md](../Agent.md)。

## 本轮纳入的改动

- 修复 Maxwell 结构化控制流的共享汇合点和相邻分支，按实际常量地址缩小局部内存初始化；动态地址仍保留完整窗口和原环绕语义。
- 共享着色器清单不再驱逐已满的近期/标题接口缓存；准确状态集合仅因使用顺序变化时复用完整准备收据。
- 复用固定版本 zstd 的 XXH3 做运行内纹理完整内容检查，保持检查范围、频率和同步；管线缓存上限由 64 MiB 增至有界 256 MiB。
- TotK 1.4.3 默认按有效 guest 优先级调度 core-0，保留单持有者、安全点交接、同级 FIFO 和互斥锁传递继承。
  线程 ID/TLS 并发分配、取消/超时/重启清理已覆盖；未改变游戏库 ABI。
- 独立测试包保存逐帧序列和低帧统计，支持全幅双摇杆及分离的攻击/跳跃脉冲；补充有界渲染/内核等待归因。
  普通 Release 保留正常优化和调度抢占，去除测试、抓帧及详细探针功能。

2 ms 全局切片、共享映射、独立录制 worker、描述符模板和清除合并没有足够稳定收益，继续沿用已记录的关闭默认值。
没有为了提高帧率降低精度、跳过绘制、删除同步或重新编译整套游戏库。

## 验证结果

最终默认独立测试包两轮达到 **30.47/29.51 FPS、1% low 18.30/18.08、最大帧 64.80/60.72 ms**，
均无 >100 ms 完成帧。继承实验的同包 on/off/on 为 low 19.21/14.46/17.41，支持尾部改善，未证明平均提速。
实际同进程重启完成线程退出、全部 25 个 reset hooks 和再次呈现；独立截图确认初始空岛、移动转向和跳跃。
这些性能数据来自独立 perftest；普通 Release 本轮验收构建、诊断隔离、编译参数和安装，没有冒充普通包长时游戏成绩。

全部测试在 Distrobox `dev` 中执行，原始日志留在 `.work/closeout-20261031/` 与本轮调度证据目录。

本轮没有宣称整游戏统一验收。完整挥剑动画、更多场景、首次遇到新管线时的卡顿、长期稳定性以及正常 2×/60 仍待验证和优化。

## 普通 Release 交付

构建命令（`dev` 内先 `source android/dev_env.sh`）：

```bash
export JOBS=2 TOTK_LTO_JOBS=1
unset TOTK_PERFORMANCE_TEST
bash android/build_totk.sh release --profile snapdragon-8elite
```

已核对最终产物对应的 92 个运行时编译单元使用 `-O3 -flto=thin -fno-fast-math`、
`-march=armv8.7-a+crypto+fp16 -mtune=oryon-1` 和 `TOTK_DIAGNOSTICS=0`。
