# 当前状态与已知问题

更新日期：2026-10-26。目标是让《王国之泪》Switch 1.4.3 在 Android ARM64 上正确、稳定运行。
已验证设备是一加 13（PJZ110、Adreno 830）；其他设备尚无本项目验收结论。

## 已确认

| 项目 | 证据与范围 |
| --- | --- |
| 输入与装载 | 四模块 NSO 身份、NPDM 程序 ID、版本隔离和库 ABI 检查已接入 |
| 游戏启动 | 正常 APK/Activity/JNI 流程已进入“海拉鲁城堡的地下” |
| 人物模型 | LDC 地址重叠及有符号偏移修正后，用户确认“模型好了” |
| 瘴气棋盘格 | Banner Turnip `v27.0.0-20261025-r5-A8xx` 配合 8-bit gather 补偿，用户确认“棋盘格没了” |
| 控制流 | 高通原厂驱动 switch 顺序落入错误已独立复现并修正；未解决剩余画面故障 |
| 资源同步 | 非零 NVN barrier 已提交 GPU 依赖；独立同步验证通过 |
| 服务初始化 | 已越过物理映射、音频工作区、缓存与临时目录等启动阻塞 |

驱动与 gather 补偿尚未在当前场景分别关闭对照，不能把改善只归因于其中一项。
原厂驱动多轮负结果保留在 [详细记录](TOTK-PORT.md)。

## 尚未解决

- **光晕矩形截断**：左上四分之一区域遮挡火把光晕，关闭项目缩放仍存在。run39 已定位到 bloom
  逐级放大合成时，实际 mip 1 左上四分之一变零。正在核对未实现的 NVN 渲染启用／条件渲染是否导致错误清除。
- **大面积场景闪烁**：人物、火焰和 UI 保留而背景变暗／缺失，尚不能断定是漏绘制、光照还是合成。
- **其他透明效果与阴影**：历史上瘴气、雾、粒子和火焰有联动消失；普通阴影可能不同频。
  换驱动后尚未逐项验收。
- 某些视角出现未实现的顶点 `DMUL` 指令，与上述故障的因果关系未证明。
- 完整音频、输入流程、存档事务／崩溃恢复、长时间运行与性能仍待验收。
  游戏已产生可读取的自动存档，但 `IFileSystem::Commit` 仍为占位。

## 构建与同步

应用开发版本为 `0.1.0-totk-dev`，它与游戏版本 1.4.3、上游应用版本是不同编号。
已合并上游 `ef7a306` / `v0.1.11-beta`，APK 构建通过。新增语言、字体、触控、生命周期修改及默认隐藏
游戏 GPU 计时的动态分辨率策略，需要结合本项目继续实机验收。

当前手机基线 run39 安装于此次合并之前，仍使用 Banner Turnip，不能视为合并后 APK 的实机结果。
游戏库是 `GAMELIB_FAST_COMPILE=ON`（全部 `-O0`），现有 FPS 不代表优化后性能。

## 保留的未适配功能

BOTW/LAS 游戏定点 hook、60 FPS／超宽屏补丁、端侧完整编译流程和 Zepp 地图不能直接用于 TOTK。
当前可复现路径为电脑生成四模块游戏库，再通过 APK 部署。
上游新增的 RomFS 文件数量检查只列出 BOTW 版本，不构成 TOTK 资源完整性验收；本项目以准备工具的
输入身份、RomFS 边界及部署清单检查为准。
